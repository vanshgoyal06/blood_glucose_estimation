# Data

Place the supplied source dataset here as:

`data/raw/dataset.xlsx`

The packaged dataset is the user-supplied workbook used during the project. The working pipeline removes duplicate rows and encodes `D/N` as 1/0.

The dataset was originally obtained from the Kaggle dataset referenced in the project conversation. The source description says the records combine true and synthetic data and that non-diabetic BGL has limited variation. These provenance claims have not been independently verified in this package.

Do not replace the dataset silently when reproducing reported metrics.
